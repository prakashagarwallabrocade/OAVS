Q.21
"ପର୍ବତ" ଶବ୍ଦର ପ୍ରତିଶବ୍ଦ କେଉଁଟି?
  1. 1. ଅଚଳା
  2. 2. ଅଚଳ
  3. 3. ଅନଳ
  4. 4. ଅମଳ
Answer: 2 — ପର୍ବତ = ଅଚଳ, ଗିରି, ଭୂଧର। ଅଚଳା = ପୃଥିବୀ, ଅନଳ = ଅଗ୍ନି, ଅମଳ = ନିର୍ମଳ।
Q.22
"ରାତି" ଶବ୍ଦର ପ୍ରତିଶବ୍ଦ କେଉଁଟି?
  1. 1. ଦାମିନୀ
  2. 2. କାମିନୀ
  3. 3. ଯାମିନୀ
  4. 4. ମେଦିନୀ
Answer: 3 — ରାତି = ଯାମିନୀ, ରଜନୀ, ନିଶା, ଶର୍ବରୀ। ଦାମିନୀ = ବିଜୁଳି, କାମିନୀ = ନାରୀ, ମେଦିନୀ = ପୃଥିବୀ।
Q.23
"ଫୁଲ" ଶବ୍ଦର ପ୍ରତିଶବ୍ଦ କେଉଁଟି?
  1. 1. ସୁମେରୁ
  2. 2. ସୁଧା
  3. 3. ସୁରଭି
  4. 4. ସୁମନ
Answer: 4 — ଫୁଲ = ସୁମନ, କୁସୁମ, ପୁଷ୍ପ। ସୁମେରୁ = ଏକ ପର୍ବତ, ସୁଧା = ଅମୃତ, ସୁରଭି = ସୁଗନ୍ଧ।
Q.24
"ଉନ୍ନତି" ଶବ୍ଦର ବିପରୀତ ଶବ୍ଦ କେଉଁଟି?
  1. 1. ପ୍ରଗତି
  2. 2. ଅବନତି
  3. 3. ଉତ୍କର୍ଷ
  4. 4. ଉତ୍ଥାନ
Answer: 2 — ଉନ୍ନତି ର ବିପରୀତ ଅବନତି। ପ୍ରଗତି, ଉତ୍କର୍ଷ ଓ ଉତ୍ଥାନ ଉନ୍ନତିର ସମାର୍ଥକ।
Q.25
"ସାକାର" ଶବ୍ଦର ବିପରୀତ ଶବ୍ଦ କେଉଁଟି?
  1. 1. ନିରାକାର
  2. 2. ଆକୃତି
  3. 3. ବିକାର
  4. 4. ପ୍ରକାର
Answer: 1 — ସାକାର (ଆକାର ଥିବା) ର ବିପରୀତ ନିରାକାର (ଆକାର ନଥିବା)।
Q.26
"ସମ୍ପଦ" ଶବ୍ଦର ବିପରୀତ ଶବ୍ଦ କେଉଁଟି?
  1. 1. ସମ୍ପତ୍ତି
  2. 2. ଐଶ୍ୱର୍ଯ୍ୟ
  3. 3. ସୌଭାଗ୍ୟ
  4. 4. ବିପଦ
Answer: 4 — ସମ୍ପଦ ର ବିପରୀତ ବିପଦ (ଯଥା: ସମ୍ପଦ-ବିପଦରେ ସାଥୀ)।
Q.27
ନିମ୍ନଲିଖିତ ମଧ୍ୟରୁ ଶୁଦ୍ଧ ବନାନଟି ବାଛନ୍ତୁ।
  1. 1. ସ୍ମଶାନ
  2. 2. ଶ୍ମସାନ
  3. 3. ଶ୍ମଶାନ
  4. 4. ଶମଶାନ
Answer: 3 — ଶୁଦ୍ଧ ବନାନ: ଶ୍ମଶାନ (ଉଭୟ ସ୍ଥାନରେ ତାଳବ୍ୟ ଶ)।
Q.28
ନିମ୍ନଲିଖିତ ମଧ୍ୟରୁ ଶୁଦ୍ଧ ବନାନଟି ବାଛନ୍ତୁ।
  1. 1. ପୈତ୍ରିକ
  2. 2. ପୈତ୍ରୀକ
  3. 3. ପୈତୃକି
  4. 4. ପୈତୃକ
Answer: 4 — ଶୁଦ୍ଧ ବନାନ: ପୈତୃକ (ପିତୃ + ଇକ, ଋ-କାର ସହ)।
Q.29
ନିମ୍ନଲିଖିତ ମଧ୍ୟରୁ କେଉଁଟି ଅଶୁଦ୍ଧ?
  1. 1. ଉପରୋକ୍ତ
  2. 2. ଅତ୍ୟଧିକ
  3. 3. ଇତ୍ୟାଦି
  4. 4. ଅନୁଷ୍ଠାନ
Answer: 1 — 'ଉପରୋକ୍ତ' ଭୁଲ। ଶୁଦ୍ଧ ରୂପ 'ଉପର୍ଯ୍ୟୁକ୍ତ' (ଉପରି + ଉକ୍ତ)।
Q.30
"ଯିଏ ଭବିଷ୍ୟତକୁ ଆଗରୁ ଦେଖିପାରେ" — ଏକପଦରେ ପ୍ରକାଶ କରନ୍ତୁ।
  1. 1. ଦୂରବର୍ତ୍ତୀ
  2. 2. ଦୂରଦର୍ଶୀ
  3. 3. ଦୂରଗାମୀ
  4. 4. ଦୂରଭାଷ
Answer: 2 — ଭବିଷ୍ୟତକୁ ଆଗରୁ ଦେଖିପାରୁଥିବା = ଦୂରଦର୍ଶୀ। ଦୂରବର୍ତ୍ତୀ = ଦୂରରେ ଥିବା, ଦୂରଗାମୀ = ଦୂରକୁ ଯାଉଥିବା।
Q.31
"ଯାହା ପଢ଼ିବା ଯୋଗ୍ୟ" — ଏକପଦରେ ପ୍ରକାଶ କରନ୍ତୁ।
  1. 1. ପୂଜନୀୟ
  2. 2. ପଠନୀୟ
  3. 3. ଦର୍ଶନୀୟ
  4. 4. ଶ୍ରବଣୀୟ
Answer: 2 — ପଢ଼ିବା ଯୋଗ୍ୟ = ପଠନୀୟ। ଦେଖିବା ଯୋଗ୍ୟ = ଦର୍ଶନୀୟ, ଶୁଣିବା ଯୋଗ୍ୟ = ଶ୍ରବଣୀୟ।
Q.32
"ଯେଉଁ ନାରୀର ସ୍ୱାମୀ ଜୀବିତ" — ଏକପଦରେ ପ୍ରକାଶ କରନ୍ତୁ।
  1. 1. ବିଧବା
  2. 2. ସ୍ୱାମିନୀ
  3. 3. ସତୀ
  4. 4. ସଧବା
Answer: 4 — ସ୍ୱାମୀ ଜୀବିତ ଥିବା ନାରୀ = ସଧବା। ସ୍ୱାମୀ ମୃତ ହୋଇଥିବା ନାରୀ = ବିଧବା।
Q.33
"ଯିଏ ଅନ୍ୟ ଉପରେ ନିର୍ଭର କରେ" — ଏକପଦରେ ପ୍ରକାଶ କରନ୍ତୁ।
  1. 1. ସ୍ୱାବଲମ୍ବୀ
  2. 2. ଆତ୍ମନିର୍ଭର
  3. 3. ପରୋପକାରୀ
  4. 4. ପରନିର୍ଭରଶୀଳ
Answer: 4 — ଅନ୍ୟ ଉପରେ ନିର୍ଭର କରୁଥିବା = ପରନିର୍ଭରଶୀଳ। ସ୍ୱାବଲମ୍ବୀ ଓ ଆତ୍ମନିର୍ଭର ଏହାର ବିପରୀତ।
Q.34
"ମୁହଁରେ ଚୂନ କାଳି ବୋଳିବା" ରୂଢ଼ିର ଅର୍ଥ କ'ଣ?
  1. 1. ସାଜସଜ୍ଜା କରିବା
  2. 2. ଅପମାନିତ ବା ବଦନାମ କରିବା
  3. 3. ଚିତ୍ର ଆଙ୍କିବା
  4. 4. ଲୁଚାଇ ରଖିବା
Answer: 2 — ମୁହଁରେ ଚୂନ କାଳି ବୋଳିବା = କୁଳ ବା ପରିବାରକୁ ଅପମାନିତ କରିବା, ବଦନାମ କରିବା।
Q.35
"ଦୂରରୁ ପାହାଡ଼ ସୁନ୍ଦର" ଢଗର ଅର୍ଥ କ'ଣ?
  1. 1. ପାହାଡ଼ ଚଢ଼ିବା କଷ୍ଟକର
  2. 2. ପ୍ରକୃତି ସର୍ବଦା ସୁନ୍ଦର
  3. 3. ଦୂରରୁ ସବୁ ଜିନିଷ ଭଲ ଦିଶେ, ପାଖରେ ତା'ର ଦୋଷ ଜଣାପଡ଼େ
  4. 4. ଦୂରଦେଶ ଭ୍ରମଣ କରିବା ଉଚିତ
Answer: 3 — ଏହି ଢଗର ଅର୍ଥ: ଦୂରରୁ ଯାହା ଆକର୍ଷଣୀୟ ଦିଶେ, ପାଖକୁ ଗଲେ ତା'ର ଅସୁବିଧା ଜଣାପଡ଼େ।
Q.36
ଶୂନ୍ୟସ୍ଥାନ ପୂରଣ କରନ୍ତୁ।
ସେ ଜଣେ ______ ବ୍ୟକ୍ତି।
  1. 1. ବିଦ୍ୟା
  2. 2. ବିଦ୍ୱତା
  3. 3. ବିଦ୍ୱାନ
  4. 4. ବିଦ୍ୟାଳୟ
Answer: 3 — 'ବ୍ୟକ୍ତି' ବିଶେଷ୍ୟକୁ ବିଶେଷଣ ଦରକାର। 'ବିଦ୍ୱାନ' ବିଶେଷଣ, ଅନ୍ୟଗୁଡ଼ିକ ବିଶେଷ୍ୟ।
Q.37
ନିମ୍ନଲିଖିତ ମଧ୍ୟରୁ ଶୁଦ୍ଧ ବାକ୍ୟଟି ବାଛନ୍ତୁ।
  1. 1. ତାଙ୍କର ଏକମାତ୍ର ପୁଅ ବିଦେଶରେ ଅଛି।
  2. 2. ତାଙ୍କର ଏକମାତ୍ର ଗୋଟିଏ ପୁଅ ବିଦେଶରେ ଅଛି।
  3. 3. ତାଙ୍କର କେବଳ ଏକମାତ୍ର ପୁଅ ବିଦେଶରେ ଅଛି।
  4. 4. ତାଙ୍କର ଏକମାତ୍ର ପୁଅମାନେ ବିଦେଶରେ ଅଛନ୍ତି।
Answer: 1 — 'ଏକମାତ୍ର' ସହ 'ଗୋଟିଏ' ବା 'କେବଳ' ଲେଖିବା ଦ୍ୱିରୁକ୍ତି ଦୋଷ, ଏବଂ 'ଏକମାତ୍ର' ସହ ବହୁବଚନ 'ପୁଅମାନେ' ଅସଙ୍ଗତ।
Q.38
"ରାମଙ୍କ ଦ୍ୱାରା ରାବଣ ବଧ ହେଲା।" — ଏହି ବାକ୍ୟର କର୍ତ୍ତୃବାଚ୍ୟ ରୂପ କେଉଁଟି?
  1. 1. ରାବଣ ରାମଙ୍କୁ ବଧ କଲା।
  2. 2. ରାମ ରାବଣକୁ ବଧ କଲେ।
  3. 3. ରାମଙ୍କୁ ରାବଣ ବଧ କଲା।
  4. 4. ରାମ ରାବଣ ଦ୍ୱାରା ବଧ ହେଲେ।
Answer: 2 — କର୍ମବାଚ୍ୟର 'ରାମଙ୍କ ଦ୍ୱାରା' କର୍ତ୍ତୃବାଚ୍ୟରେ କର୍ତ୍ତା 'ରାମ' ହୁଏ ଏବଂ 'ରାବଣ' କର୍ମ 'ରାବଣକୁ' ହୁଏ।
Q.39
ସେ କହିଲା, "ମୁଁ କାଲି ଆସିବି।" — ଏହାର ପରୋକ୍ଷ ଉକ୍ତି କେଉଁଟି?
  1. 1. ସେ କହିଲା ଯେ ମୁଁ କାଲି ଆସିବି।
  2. 2. ସେ କହିଲା ଯେ ସେ କାଲି ଆସିଥିଲା।
  3. 3. ସେ କହିଲା ଯେ ସେ ପରଦିନ ଆସିବ।
  4. 4. ସେ କହିଲା ଯେ ତୁମେ ପରଦିନ ଆସିବ।
Answer: 3 — ପରୋକ୍ଷ ଉକ୍ତିରେ 'ମୁଁ' 'ସେ' ହୁଏ, 'ଆସିବି' 'ଆସିବ' ହୁଏ ଏବଂ 'କାଲି' 'ପରଦିନ' ହୁଏ।
Q.40
ନିମ୍ନଲିଖିତ ଅଂଶଗୁଡ଼ିକୁ ସଜାଇ ଏକ ଅର୍ଥପୂର୍ଣ୍ଣ ବାକ୍ୟ ଗଠନ କରନ୍ତୁ।
P: ଉତ୍କଳମଣି ଗୋପବନ୍ଧୁ ଦାସ
Q: 'ସମାଜ'
R: ପ୍ରତିଷ୍ଠା କରିଥିଲେ।
S: ଖବରକାଗଜ
  1. 1. QPRS
  2. 2. SRPQ
  3. 3. PQSR
  4. 4. RQPS
Answer: 3 — ଶୁଦ୍ଧ ବାକ୍ୟ: ଉତ୍କଳମଣି ଗୋପବନ୍ଧୁ ଦାସ (P) 'ସମାଜ' (Q) ଖବରକାଗଜ (S) ପ୍ରତିଷ୍ଠା କରିଥିଲେ (R)। ('ସମାଜ' ୧୯୧୯ ମସିହାରେ ପ୍ରତିଷ୍ଠିତ।)
