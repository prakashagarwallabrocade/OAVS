Q.1
The following sentence has been split into four segments. Identify the segment that contains a grammatical error.
The number of students / are increasing / every year / in this school.
  1. 1. are increasing
  2. 2. The number of students
  3. 3. every year
  4. 4. in this school.
Answer: 1 — 'The number of' is singular and takes 'is'. ('A number of' is plural.)
Q.2
The following sentence has been split into four segments. Identify the segment that contains a grammatical error.
He is one of those leaders / who has / always stood / by the poor.
  1. 1. He is one of those leaders
  2. 2. always stood
  3. 3. by the poor.
  4. 4. who has
Answer: 4 — In 'one of those … who', the relative pronoun refers to the plural 'leaders', so the verb is plural: 'who have always stood'.
Q.3
The following sentence has been split into four segments. Identify the segment that contains a grammatical error.
I have been knowing him / since / my childhood / in Cuttack.
  1. 1. I have been knowing him
  2. 2. since
  3. 3. my childhood
  4. 4. in Cuttack.
Answer: 1 — 'Know' is a stative verb and is not used in continuous tenses: 'I have known him since my childhood'.
Q.4
Select the most appropriate option to fill in the blank.
The jury ______ divided in their opinions about the verdict.
  1. 1. were
  2. 2. was
  3. 3. is
  4. 4. has
Answer: 1 — When the members of a collective noun act as individuals (here, holding different opinions, shown by 'their'), the verb is plural.
Q.5
Select the most appropriate option to fill in the blank.
She prefers reading books ______ watching television.
  1. 1. than
  2. 2. to
  3. 3. over than
  4. 4. rather
Answer: 2 — 'Prefer' is followed by 'to': prefer X to Y.
Q.6
Select the most appropriate option to fill in the blank.
Neither he nor I ______ responsible for the loss.
  1. 1. is
  2. 2. are
  3. 3. were
  4. 4. am
Answer: 4 — With 'neither … nor', the verb agrees with the nearer subject, 'I', so it is 'am'.
Q.7
Select the most appropriate synonym of the given word.
Obdurate
  1. 1. Obedient
  2. 2. Gentle
  3. 3. Stubborn
  4. 4. Hesitant
Answer: 3 — Obdurate means stubbornly refusing to change one's opinion.
Q.8
Select the most appropriate synonym of the given word.
Sagacious
  1. 1. Saintly
  2. 2. Talkative
  3. 3. Foolish
  4. 4. Wise
Answer: 4 — Sagacious means having keen judgement, i.e. wise. It has nothing to do with 'saintly' despite the similar sound.
Q.9
Select the most appropriate antonym of the given word.
Gregarious
  1. 1. Sociable
  2. 2. Friendly
  3. 3. Reclusive
  4. 4. Outgoing
Answer: 3 — Gregarious means fond of company. Reclusive (avoiding company) is the opposite. The other three are synonyms.
Q.10
Select the most appropriate antonym of the given word.
Laconic
  1. 1. Concise
  2. 2. Terse
  3. 3. Brief
  4. 4. Verbose
Answer: 4 — Laconic means using very few words. Verbose (using too many words) is the opposite.
Q.11
Select the correctly spelt word.
  1. 1. Concientious
  2. 2. Conscientous
  3. 3. Consciencious
  4. 4. Conscientious
Answer: 4 — The correct spelling is con-sci-en-tious.
Q.12
Select the INCORRECTLY spelt word.
  1. 1. Receipt
  2. 2. Deceive
  3. 3. Recieve
  4. 4. Ceiling
Answer: 3 — The rule is 'i before e except after c': receive. The others are correct.
Q.13
Select the most appropriate meaning of the given idiom.
To bell the cat
  1. 1. To make a lot of noise
  2. 2. To catch a thief red-handed
  3. 3. To waste time on useless work
  4. 4. To undertake a risky task for the common good
Answer: 4 — From the fable of the mice: someone must take the dangerous step of tying a bell on the cat.
Q.14
Select the most appropriate meaning of the given idiom.
A red-letter day
  1. 1. A day of bad news
  2. 2. A public holiday for banks
  3. 3. A memorable and important day
  4. 4. A day of danger
Answer: 3 — Important days were once marked in red on calendars.
Q.15
Select the option that can be used as a one-word substitute for the given group of words.
A remedy for all diseases or difficulties
  1. 1. Placebo
  2. 2. Panacea
  3. 3. Antidote
  4. 4. Vaccine
Answer: 2 — A panacea is a cure-all. An antidote counters a specific poison, and a placebo is a dummy medicine.
Q.16
Select the option that can be used as a one-word substitute for the given group of words.
One who walks in sleep
  1. 1. Somniloquist
  2. 2. Insomniac
  3. 3. Noctivagant
  4. 4. Somnambulist
Answer: 4 — A somnambulist walks in sleep. A somniloquist talks in sleep, and an insomniac cannot sleep.
Q.17
Select the most appropriate option to improve the underlined part of the sentence. If no improvement is needed, select 'No improvement'.
No sooner did he see the tiger when he ran away.
  1. 1. than he ran away
  2. 2. then he ran away
  3. 3. that he ran away
  4. 4. No improvement
Answer: 1 — 'No sooner' is always followed by 'than'.
Q.18
Select the option that expresses the given sentence in passive voice.
They are building a new bridge over the Mahanadi.
  1. 1. A new bridge was being built over the Mahanadi by them.
  2. 2. A new bridge has been built over the Mahanadi by them.
  3. 3. A new bridge is built over the Mahanadi by them.
  4. 4. A new bridge is being built over the Mahanadi by them.
Answer: 4 — Present continuous active (are building) becomes 'is/are being + past participle' in the passive.
Q.19
Select the option that expresses the given sentence in indirect speech.
He said, "Let us go for a walk."
  1. 1. He proposed that they should go for a walk.
  2. 2. He said that let us go for a walk.
  3. 3. He told that we should go for a walk.
  4. 4. He ordered them to go for a walk.
Answer: 1 — 'Let us' expressing a suggestion becomes 'proposed/suggested that they should …' in indirect speech.
Q.20
The given sentence is divided into parts. The first part is fixed. Arrange the remaining parts in the correct order.
The Rourkela Steel Plant,
P: was the first
Q: with German collaboration,
R: integrated steel plant in the public sector
S: set up
  1. 1. SQPR
  2. 2. QSPR
  3. 3. PRSQ
  4. 4. SPQR
Answer: 1 — The Rourkela Steel Plant, set up (S) with German collaboration (Q), was the first (P) integrated steel plant in the public sector (R).
