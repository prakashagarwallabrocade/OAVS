Q.21
"ନଦୀ" ଶବ୍ଦର ପ୍ରତିଶବ୍ଦ କେଉଁଟି?
  1. 1. ତରଣି
  2. 2. ତରୁ
  3. 3. ତଡ଼ିତ
  4. 4. ତଟିନୀ
Answer: 4 — ନଦୀ = ତଟିନୀ, ସରିତ, ତରଙ୍ଗିଣୀ। ତରଣି = ସୂର୍ଯ୍ୟ/ନୌକା, ତରୁ = ଗଛ, ତଡ଼ିତ = ବିଜୁଳି।
Q.22
"ହାତୀ" ଶବ୍ଦର ପ୍ରତିଶବ୍ଦ କେଉଁଟି?
  1. 1. ଦନ୍ତୀ
  2. 2. ଦାନବ
  3. 3. ଦନୁଜ
  4. 4. ଦାନ୍ତ
Answer: 1 — ହାତୀ = ଦନ୍ତୀ, ଗଜ, କରୀ, ହସ୍ତୀ। ଦାନବ ଓ ଦନୁଜ ଅର୍ଥ ଅସୁର।
Q.23
"ମେଘ" ଶବ୍ଦର ପ୍ରତିଶବ୍ଦ କେଉଁଟି?
  1. 1. ଜଳଧି
  2. 2. ଜଳଦ
  3. 3. ଜଳଜ
  4. 4. ଜଳଚର
Answer: 2 — ମେଘ = ଜଳଦ (ଜଳ ଦେଉଥିବା), ନୀରଦ, ଘନ। ଜଳଧି = ସମୁଦ୍ର, ଜଳଜ = ପଦ୍ମ, ଜଳଚର = ଜଳରେ ରହୁଥିବା ପ୍ରାଣୀ।
Q.24
"କୃତଜ୍ଞ" ଶବ୍ଦର ବିପରୀତ ଶବ୍ଦ କେଉଁଟି?
  1. 1. କୃତଘ୍ନ
  2. 2. କୃତାର୍ଥ
  3. 3. କୃପଣ
  4. 4. କୃତୀ
Answer: 1 — କୃତଜ୍ଞ (ଉପକାର ମନେ ରଖୁଥିବା) ର ବିପରୀତ କୃତଘ୍ନ (ଉପକାର ଭୁଲିଯାଉଥିବା)।
Q.25
"ସଦୟ" ଶବ୍ଦର ବିପରୀତ ଶବ୍ଦ କେଉଁଟି?
  1. 1. ସହୃଦୟ
  2. 2. ଦୟାଳୁ
  3. 3. ନିର୍ଦ୍ଦୟ
  4. 4. ଉଦାର
Answer: 3 — ସଦୟ (ଦୟାଯୁକ୍ତ) ର ବିପରୀତ ନିର୍ଦ୍ଦୟ।
Q.26
"ଆବିର୍ଭାବ" ଶବ୍ଦର ବିପରୀତ ଶବ୍ଦ କେଉଁଟି?
  1. 1. ପ୍ରାଦୁର୍ଭାବ
  2. 2. ତିରୋଭାବ
  3. 3. ଅଭାବ
  4. 4. ସ୍ୱଭାବ
Answer: 2 — ଆବିର୍ଭାବ (ପ୍ରକଟ ହେବା) ର ବିପରୀତ ତିରୋଭାବ (ଅନ୍ତର୍ଦ୍ଧାନ ହେବା)। ପ୍ରାଦୁର୍ଭାବ ଆବିର୍ଭାବର ସମାର୍ଥକ।
Q.27
ନିମ୍ନଲିଖିତ ମଧ୍ୟରୁ ଶୁଦ୍ଧ ବନାନଟି ବାଛନ୍ତୁ।
  1. 1. ଦୁରାବସ୍ଥା
  2. 2. ଦୁରବସ୍ଥା
  3. 3. ଦୂରବସ୍ଥା
  4. 4. ଦୁର୍ବସ୍ଥା
Answer: 2 — ଶୁଦ୍ଧ ବନାନ: ଦୁରବସ୍ଥା (ଦୁଃ + ଅବସ୍ଥା)। 'ଦୁରାବସ୍ଥା' ଏକ ସାଧାରଣ ଭୁଲ।
Q.28
ନିମ୍ନଲିଖିତ ମଧ୍ୟରୁ ଶୁଦ୍ଧ ବନାନଟି ବାଛନ୍ତୁ।
  1. 1. ଉଚ୍ଛାସ
  2. 2. ଉଛ୍ୱାସ
  3. 3. ଉଚ୍ଚ୍ୱାସ
  4. 4. ଉଚ୍ଛ୍ୱାସ
Answer: 4 — ଶୁଦ୍ଧ ବନାନ: ଉଚ୍ଛ୍ୱାସ (ଉତ୍ + ଶ୍ୱାସ)।
Q.29
ନିମ୍ନଲିଖିତ ମଧ୍ୟରୁ କେଉଁଟି ଅଶୁଦ୍ଧ?
  1. 1. ସାମର୍ଥ୍ୟତା
  2. 2. ମହତ୍ତ୍ୱ
  3. 3. ଦାୟିତ୍ୱ
  4. 4. ସୌଜନ୍ୟ
Answer: 1 — 'ସାମର୍ଥ୍ୟ' ନିଜେ ଭାବବାଚକ ବିଶେଷ୍ୟ, ତା' ସହ ପୁଣି '-ତା' ଯୋଗ କରିବା ଭୁଲ। ଶୁଦ୍ଧ: ସାମର୍ଥ୍ୟ।
Q.30
"ଯାହାକୁ ଏଡ଼ାଇ ହୁଏ ନାହିଁ" — ଏକପଦରେ ପ୍ରକାଶ କରନ୍ତୁ।
  1. 1. ଅନିର୍ବଚନୀୟ
  2. 2. ଅନିବାର୍ଯ୍ୟ
  3. 3. ଅଦମ୍ୟ
  4. 4. ଅଗମ୍ୟ
Answer: 2 — ଏଡ଼ାଇ ନ ହେଉଥିବା = ଅନିବାର୍ଯ୍ୟ। ଅନିର୍ବଚନୀୟ = ଯାହା କହି ହୁଏ ନାହିଁ, ଅଦମ୍ୟ = ଯାହାକୁ ଦମନ କରିହୁଏ ନାହିଁ, ଅଗମ୍ୟ = ଯେଉଁଠି ଯାଇହୁଏ ନାହିଁ।
Q.31
"ଯାହା ବହୁ ଦିନରୁ ଚାଲିଆସୁଛି" — ଏକପଦରେ ପ୍ରକାଶ କରନ୍ତୁ।
  1. 1. ଅଭିନବ
  2. 2. ଚିରାଚରିତ
  3. 3. ଆଧୁନିକ
  4. 4. ସାମୟିକ
Answer: 2 — ବହୁ ଦିନରୁ ଚାଲିଆସୁଥିବା = ଚିରାଚରିତ (ଯଥା: ଚିରାଚରିତ ପ୍ରଥା)। ଅଭିନବ = ନୂଆ।
Q.32
"ଯିଏ ଅନ୍ୟର ଉନ୍ନତି ଦେଖି ସହି ପାରେ ନାହିଁ" — ଏକପଦରେ ପ୍ରକାଶ କରନ୍ତୁ।
  1. 1. ପରୋପକାରୀ
  2. 2. ପରାଧୀନ
  3. 3. ପରଦେଶୀ
  4. 4. ପରଶ୍ରୀକାତର
Answer: 4 — ଅନ୍ୟର ଶ୍ରୀ (ଉନ୍ନତି) ଦେଖି କାତର ହେଉଥିବା = ପରଶ୍ରୀକାତର।
Q.33
"ଯେଉଁ ଭୂମିରେ ଫସଲ ଉପୁଜେ ନାହିଁ" — ଏକପଦରେ ପ୍ରକାଶ କରନ୍ତୁ।
  1. 1. ଉର୍ବର
  2. 2. ଉପତ୍ୟକା
  3. 3. ଊର୍ଦ୍ଧ୍ୱ
  4. 4. ଊଷର
Answer: 4 — ଫସଲ ନ ଉପୁଜୁଥିବା ଭୂମି = ଊଷର। ଉର୍ବର ଏହାର ବିପରୀତ।
Q.34
"ଆଖିରେ ଧୂଳି ଦେବା" ରୂଢ଼ିର ଅର୍ଥ କ'ଣ?
  1. 1. ଅପମାନ କରିବା
  2. 2. ପ୍ରତାରଣା କରିବା
  3. 3. ଦୃଷ୍ଟି ହରାଇବା
  4. 4. ଲଜ୍ଜିତ କରିବା
Answer: 2 — ଆଖିରେ ଧୂଳି ଦେବା = କାହାକୁ ଠକିବା ବା ପ୍ରତାରଣା କରିବା।
Q.35
"ଯେତେ ଗର୍ଜେ ସେତେ ବର୍ଷେ ନାହିଁ" ଢଗର ଅର୍ଥ କ'ଣ?
  1. 1. ମେଘ ଗର୍ଜିଲେ ବର୍ଷା ହୁଏ
  2. 2. ବେଶି ପରିଶ୍ରମରେ ବେଶି ଫଳ
  3. 3. ରାଗୀ ଲୋକ ଶୀଘ୍ର ଶାନ୍ତ ହୁଏ
  4. 4. ଯିଏ ବେଶି କହେ ସେ କମ୍ କାମ କରେ
Answer: 4 — ଏହି ଢଗର ଅର୍ଥ: ଯିଏ ଅଧିକ ବଡ଼ାଇ କରେ ବା ଧମକ ଦିଏ, ସେ ପ୍ରକୃତରେ କମ୍ କରେ।
Q.36
ଶୂନ୍ୟସ୍ଥାନ ପୂରଣ କରନ୍ତୁ।
ଗୁରୁଜନଙ୍କୁ ______ କରିବା ଉଚିତ।
  1. 1. ସମ୍ମାନିତ
  2. 2. ସମ୍ମାନୀୟ
  3. 3. ସମାନ
  4. 4. ସମ୍ମାନ
Answer: 4 — 'କରିବା' କ୍ରିୟା ସହ ବିଶେଷ୍ୟ 'ସମ୍ମାନ' ବସିବ। ସମ୍ମାନିତ ଓ ସମ୍ମାନୀୟ ବିଶେଷଣ।
Q.37
ନିମ୍ନଲିଖିତ ମଧ୍ୟରୁ ଶୁଦ୍ଧ ବାକ୍ୟଟି ବାଛନ୍ତୁ।
  1. 1. ମୁଖ୍ୟମନ୍ତ୍ରୀ ସଭାରେ ଭାଷଣ ଦେଲା।
  2. 2. ମୁଖ୍ୟମନ୍ତ୍ରୀ ସଭାରେ ଭାଷଣ ଦେଲୁ।
  3. 3. ମୁଖ୍ୟମନ୍ତ୍ରୀ ସଭାରେ ଭାଷଣ ଦେଲେ।
  4. 4. ମୁଖ୍ୟମନ୍ତ୍ରୀ ସଭାରେ ଭାଷଣ ଦେଲି।
Answer: 3 — ସମ୍ମାନୀୟ କର୍ତ୍ତା ସହ ସମ୍ମାନସୂଚକ କ୍ରିୟା 'ଦେଲେ' ବ୍ୟବହୃତ ହୁଏ।
Q.38
"ଶିକ୍ଷକ ଛାତ୍ରମାନଙ୍କୁ ପଢ଼ାଉଛନ୍ତି।" — ଏହି ବାକ୍ୟର କର୍ମବାଚ୍ୟ ରୂପ କେଉଁଟି?
  1. 1. ଶିକ୍ଷକଙ୍କ ଦ୍ୱାରା ଛାତ୍ରମାନଙ୍କୁ ପଢ଼ାଗଲା।
  2. 2. ଶିକ୍ଷକଙ୍କ ଦ୍ୱାରା ଛାତ୍ରମାନଙ୍କୁ ପଢ଼ାଯାଉଛି।
  3. 3. ଛାତ୍ରମାନେ ଶିକ୍ଷକଙ୍କୁ ପଢ଼ାଉଛନ୍ତି।
  4. 4. ଶିକ୍ଷକ ଛାତ୍ରମାନଙ୍କ ଦ୍ୱାରା ପଢ଼ୁଛନ୍ତି।
Answer: 2 — ଘଟମାନ ବର୍ତ୍ତମାନ 'ପଢ଼ାଉଛନ୍ତି' କର୍ମବାଚ୍ୟରେ 'ପଢ଼ାଯାଉଛି' ହୁଏ ଏବଂ କର୍ତ୍ତା ସହ 'ଦ୍ୱାରା' ଯୋଗ ହୁଏ। 'ପଢ଼ାଗଲା' ଅତୀତ କାଳ।
Q.39
ମା' କହିଲେ, "ବାହାରକୁ ଯାଅ ନାହିଁ।" — ଏହାର ପରୋକ୍ଷ ଉକ୍ତି କେଉଁଟି?
  1. 1. ମା' କହିଲେ ଯେ ବାହାରକୁ ଯାଅ ନାହିଁ।
  2. 2. ମା' ବାହାରକୁ ଯିବାକୁ ଆଦେଶ ଦେଲେ।
  3. 3. ମା' ବାହାରକୁ ଯିବାକୁ ବାରଣ କଲେ।
  4. 4. ମା' ବାହାରକୁ ଗଲେ ନାହିଁ।
Answer: 3 — ନିଷେଧସୂଚକ ଆଜ୍ଞାର ପରୋକ୍ଷ ଉକ୍ତିରେ 'ବାରଣ କଲେ' ବ୍ୟବହୃତ ହୁଏ। 'ଆଦେଶ ଦେଲେ' ଅର୍ଥ ଓଲଟାଇଦିଏ।
Q.40
ନିମ୍ନଲିଖିତ ଅଂଶଗୁଡ଼ିକୁ ସଜାଇ ଏକ ଅର୍ଥପୂର୍ଣ୍ଣ ବାକ୍ୟ ଗଠନ କରନ୍ତୁ।
P: ସର୍ବବୃହତ୍
Q: ଚିଲିକା
R: ଲବଣାକ୍ତ ଜଳ ହ୍ରଦ।
S: ଏସିଆର
  1. 1. QSPR
  2. 2. SQPR
  3. 3. QPSR
  4. 4. PRQS
Answer: 1 — ଶୁଦ୍ଧ ବାକ୍ୟ: ଚିଲିକା (Q) ଏସିଆର (S) ସର୍ବବୃହତ୍ (P) ଲବଣାକ୍ତ ଜଳ ହ୍ରଦ (R)।
