Q.21
"ସମୁଦ୍ର" ଶବ୍ଦର ପ୍ରତିଶବ୍ଦ କେଉଁଟି?
  1. 1. ସରୋବର
  2. 2. ନଦୀ
  3. 3. ପର୍ବତ
  4. 4. ସାଗର
Answer: 4 — ସମୁଦ୍ର = ସାଗର, ଜଳଧି, ପାରାବାର। ସରୋବର ଅର୍ଥ ପୋଖରୀ ବା ହ୍ରଦ।
Q.22
"ସୂର୍ଯ୍ୟ" ଶବ୍ଦର ପ୍ରତିଶବ୍ଦ କେଉଁଟି?
  1. 1. ଭାସ୍କର
  2. 2. ସୁଧାକର
  3. 3. ନିଶାକର
  4. 4. ଶଶୀ
Answer: 1 — ସୂର୍ଯ୍ୟ = ଭାସ୍କର, ଦିବାକର, ରବି। ସୁଧାକର, ନିଶାକର ଓ ଶଶୀ ଚନ୍ଦ୍ରର ପ୍ରତିଶବ୍ଦ।
Q.23
"ପଦ୍ମ" ଶବ୍ଦର ପ୍ରତିଶବ୍ଦ କେଉଁଟି?
  1. 1. ପଙ୍କଜ
  2. 2. ପବନ
  3. 3. ପାବକ
  4. 4. ପୀୟୂଷ
Answer: 1 — ପଦ୍ମ = ପଙ୍କଜ, କମଳ, ସରୋଜ, ଅରବିନ୍ଦ। ପବନ = ବାୟୁ, ପାବକ = ଅଗ୍ନି, ପୀୟୂଷ = ଅମୃତ।
Q.24
"ଆଦାନ" ଶବ୍ଦର ବିପରୀତ ଶବ୍ଦ କେଉଁଟି?
  1. 1. ଆଦର
  2. 2. ଗ୍ରହଣ
  3. 3. ସମ୍ମାନ
  4. 4. ପ୍ରଦାନ
Answer: 4 — ଆଦାନ (ନେବା) ର ବିପରୀତ ପ୍ରଦାନ (ଦେବା)। ଗ୍ରହଣ ଆଦାନର ସମାର୍ଥକ।
Q.25
"ଉଦୟ" ଶବ୍ଦର ବିପରୀତ ଶବ୍ଦ କେଉଁଟି?
  1. 1. ଉନ୍ନତି
  2. 2. ପ୍ରକାଶ
  3. 3. ଅସ୍ତ
  4. 4. ଆରମ୍ଭ
Answer: 3 — ଉଦୟ ର ବିପରୀତ ଅସ୍ତ।
Q.26
"ସୁଲଭ" ଶବ୍ଦର ବିପରୀତ ଶବ୍ଦ କେଉଁଟି?
  1. 1. ସରଳ
  2. 2. ଦୁର୍ବଳ
  3. 3. ସୁନ୍ଦର
  4. 4. ଦୁର୍ଲଭ
Answer: 4 — ସୁଲଭ (ସହଜରେ ମିଳୁଥିବା) ର ବିପରୀତ ଦୁର୍ଲଭ (ସହଜରେ ମିଳୁ ନଥିବା)।
Q.27
ନିମ୍ନଲିଖିତ ମଧ୍ୟରୁ ଶୁଦ୍ଧ ବନାନଟି ବାଛନ୍ତୁ।
  1. 1. ଉଜ୍ୱଳ
  2. 2. ଉଜଜ୍ୱଳ
  3. 3. ଉଜ୍ଜଳ
  4. 4. ଉଜ୍ଜ୍ୱଳ
Answer: 4 — ଶୁଦ୍ଧ ବନାନ: ଉଜ୍ଜ୍ୱଳ (ଉତ୍ + ଜ୍ୱଳ)।
Q.28
ନିମ୍ନଲିଖିତ ମଧ୍ୟରୁ ଶୁଦ୍ଧ ବନାନଟି ବାଛନ୍ତୁ।
  1. 1. ପରିକ୍ଷା
  2. 2. ପରୀକ୍ଶା
  3. 3. ପରୀକ୍ଷା
  4. 4. ପରିକ୍ଷ୍ୟା
Answer: 3 — ଶୁଦ୍ଧ ବନାନ: ପରୀକ୍ଷା (ଦୀର୍ଘ ଈ-କାର ସହ)।
Q.29
ନିମ୍ନଲିଖିତ ମଧ୍ୟରୁ ଶୁଦ୍ଧ ବନାନଟି ବାଛନ୍ତୁ।
  1. 1. ଆଶିର୍ବାଦ
  2. 2. ଆଷୀର୍ବାଦ
  3. 3. ଆଶୀର୍ବାଦ
  4. 4. ଆଶୀରବାଦ
Answer: 3 — ଶୁଦ୍ଧ ବନାନ: ଆଶୀର୍ବାଦ (ତାଳବ୍ୟ ଶ, ଦୀର୍ଘ ଈ, ରେଫ)।
Q.30
"ଯାହାର ଶତ୍ରୁ ଜନ୍ମ ହୋଇନାହିଁ" — ଏକପଦରେ ପ୍ରକାଶ କରନ୍ତୁ।
  1. 1. ଅଜାତଶତ୍ରୁ
  2. 2. ଶତ୍ରୁଘ୍ନ
  3. 3. ଅରିନ୍ଦମ
  4. 4. ଶତ୍ରୁଞ୍ଜୟ
Answer: 1 — ଯାହାର ଶତ୍ରୁ ଜନ୍ମ ହୋଇନାହିଁ = ଅଜାତଶତ୍ରୁ। ଶତ୍ରୁଘ୍ନ, ଅରିନ୍ଦମ ଓ ଶତ୍ରୁଞ୍ଜୟ ଅର୍ଥ ଶତ୍ରୁକୁ ନାଶ ବା ଜୟ କରୁଥିବା।
Q.31
"ଯିଏ ଈଶ୍ୱରଙ୍କ ଅସ୍ତିତ୍ୱରେ ବିଶ୍ୱାସ କରେ ନାହିଁ" — ଏକପଦରେ ପ୍ରକାଶ କରନ୍ତୁ।
  1. 1. ଆସ୍ତିକ
  2. 2. ଧାର୍ମିକ
  3. 3. ନାସ୍ତିକ
  4. 4. ନିରୀହ
Answer: 3 — ଈଶ୍ୱରଙ୍କୁ ବିଶ୍ୱାସ କରୁ ନଥିବା ବ୍ୟକ୍ତି = ନାସ୍ତିକ। ବିଶ୍ୱାସ କରୁଥିବା ବ୍ୟକ୍ତି = ଆସ୍ତିକ।
Q.32
"ଯାହା ପୂର୍ବରୁ କେବେ ହୋଇନାହିଁ" — ଏକପଦରେ ପ୍ରକାଶ କରନ୍ତୁ।
  1. 1. ଅଦ୍ଭୁତ
  2. 2. ଅତୀତ
  3. 3. ଭବିଷ୍ୟତ
  4. 4. ଅଭୂତପୂର୍ବ
Answer: 4 — ଯାହା ପୂର୍ବରୁ କେବେ ହୋଇନାହିଁ = ଅଭୂତପୂର୍ବ।
Q.33
"ଯାହାକୁ ଜୟ କରିହୁଏ ନାହିଁ" — ଏକପଦରେ ପ୍ରକାଶ କରନ୍ତୁ।
  1. 1. ଅଜ୍ଞେୟ
  2. 2. ଅଜେୟ
  3. 3. ଅକ୍ଷୟ
  4. 4. ଅମର
Answer: 2 — ଯାହାକୁ ଜୟ କରିହୁଏ ନାହିଁ = ଅଜେୟ। ଅଜ୍ଞେୟ = ଯାହାକୁ ଜାଣିହୁଏ ନାହିଁ, ଅକ୍ଷୟ = ଯାହାର କ୍ଷୟ ନାହିଁ।
Q.34
"ଆକାଶ କୁସୁମ" ରୂଢ଼ିର ଅର୍ଥ କ'ଣ?
  1. 1. ସୁନ୍ଦର ଫୁଲ
  2. 2. ଅତି ଉଚ୍ଚ ସ୍ଥାନ
  3. 3. ଅସମ୍ଭବ କଳ୍ପନା
  4. 4. ବହୁତ ଧନ
Answer: 3 — ଆକାଶ କୁସୁମ = ଯାହା କେବେ ସମ୍ଭବ ନୁହେଁ, ଅସମ୍ଭବ କଳ୍ପନା।
Q.35
"ଆଖି ଲାଲ କରିବା" ରୂଢ଼ିର ଅର୍ଥ କ'ଣ?
  1. 1. କାନ୍ଦିବା
  2. 2. ରାତି ଜାଗିବା
  3. 3. ଆଖି ରୋଗ ହେବା
  4. 4. କ୍ରୋଧ କରିବା
Answer: 4 — ଆଖି ଲାଲ କରିବା = ରାଗିବା ବା କ୍ରୋଧ ପ୍ରକାଶ କରିବା।
Q.36
ଶୂନ୍ୟସ୍ଥାନ ପୂରଣ କରନ୍ତୁ।
ଗତକାଲି ମୁଁ ପୁରୀ ______।
  1. 1. ଯିବି
  2. 2. ଯାଉଛି
  3. 3. ଯାଉଥିବି
  4. 4. ଯାଇଥିଲି
Answer: 4 — 'ଗତକାଲି' ଅତୀତ କାଳ ସୂଚାଏ, ତେଣୁ ଅତୀତ କ୍ରିୟା 'ଯାଇଥିଲି' ଶୁଦ୍ଧ।
Q.37
ନିମ୍ନଲିଖିତ ମଧ୍ୟରୁ ଶୁଦ୍ଧ ବାକ୍ୟଟି ବାଛନ୍ତୁ।
  1. 1. ସମସ୍ତ ଲୋକମାନେ ସଭାକୁ ଆସିଥିଲେ।
  2. 2. ସମସ୍ତ ଲୋକ ସଭାକୁ ଆସିଥିଲେ।
  3. 3. ସମସ୍ତେ ଲୋକମାନେ ସଭାକୁ ଆସିଥିଲେ।
  4. 4. ସମସ୍ତ ଲୋକମାନଙ୍କ ସଭାକୁ ଆସିଥିଲେ।
Answer: 2 — 'ସମସ୍ତ' ବହୁବଚନ ବୁଝାଏ, ତେଣୁ ତା' ସହ 'ମାନେ' ଲଗାଇବା ଦ୍ୱିରୁକ୍ତି ଦୋଷ। ଶୁଦ୍ଧ: 'ସମସ୍ତ ଲୋକ ସଭାକୁ ଆସିଥିଲେ।'
Q.38
"ରାମ ବହି ପଢ଼େ।" — ଏହି ବାକ୍ୟର କର୍ମବାଚ୍ୟ ରୂପ କେଉଁଟି?
  1. 1. ରାମ ଦ୍ୱାରା ବହି ପଢ଼ାଗଲା।
  2. 2. ରାମ ବହି ପଢ଼ାଏ।
  3. 3. ବହି ରାମକୁ ପଢ଼େ।
  4. 4. ରାମ ଦ୍ୱାରା ବହି ପଢ଼ାଯାଏ।
Answer: 4 — କର୍ତ୍ତୃବାଚ୍ୟ ବର୍ତ୍ତମାନ କାଳ 'ପଢ଼େ' କର୍ମବାଚ୍ୟରେ 'ପଢ଼ାଯାଏ' ହୁଏ ଏବଂ କର୍ତ୍ତା ସହ 'ଦ୍ୱାରା' ଯୋଗ ହୁଏ। 'ପଢ଼ାଗଲା' ଅତୀତ କାଳ, ତେଣୁ ଭୁଲ।
Q.39
ସେ କହିଲା, "ମୁଁ ଘରକୁ ଯିବି।" — ଏହାର ପରୋକ୍ଷ ଉକ୍ତି କେଉଁଟି?
  1. 1. ସେ କହିଲା ଯେ ମୁଁ ଘରକୁ ଯିବି।
  2. 2. ସେ କହିଲା ଯେ ସେ ଘରକୁ ଯିବ।
  3. 3. ସେ କହିଲା ଯେ ସେ ଘରକୁ ଯାଇଥିଲା।
  4. 4. ସେ କହିଲା ଯେ ତୁମେ ଘରକୁ ଯିବ।
Answer: 2 — ପରୋକ୍ଷ ଉକ୍ତିରେ ପ୍ରଥମ ପୁରୁଷ 'ମୁଁ' ବକ୍ତା ଅନୁସାରେ 'ସେ' ହୁଏ ଏବଂ କ୍ରିୟା 'ଯିବି' 'ଯିବ' ହୁଏ।
Q.40
ନିମ୍ନଲିଖିତ ଅଂଶଗୁଡ଼ିକୁ ସଜାଇ ଏକ ଅର୍ଥପୂର୍ଣ୍ଣ ବାକ୍ୟ ଗଠନ କରନ୍ତୁ।
P: ଓଡ଼ିଆ ସାହିତ୍ୟରେ
Q: ଫକୀରମୋହନ ସେନାପତି
R: ବ୍ୟାସକବି
S: ଭାବେ ପରିଚିତ।
  1. 1. PQSR
  2. 2. RQPS
  3. 3. QRPS
  4. 4. QPRS
Answer: 4 — ଶୁଦ୍ଧ ବାକ୍ୟ: ଫକୀରମୋହନ ସେନାପତି (Q) ଓଡ଼ିଆ ସାହିତ୍ୟରେ (P) ବ୍ୟାସକବି (R) ଭାବେ ପରିଚିତ (S)।
