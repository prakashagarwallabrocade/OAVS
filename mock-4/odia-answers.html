Q.21
"ସୁନା" ଶବ୍ଦର ପ୍ରତିଶବ୍ଦ କେଉଁଟି?
  1. 1. ହେମନ୍ତ
  2. 2. ହିମ
  3. 3. ହେମ
  4. 4. ହୋମ
Answer: 3 — ସୁନା = ହେମ, କାଞ୍ଚନ, ସ୍ୱର୍ଣ୍ଣ। ହେମନ୍ତ = ଏକ ଋତୁ, ହିମ = କାକର/ବରଫ।
Q.22
"ପକ୍ଷୀ" ଶବ୍ଦର ପ୍ରତିଶବ୍ଦ କେଉଁଟି?
  1. 1. ଭୁଜଙ୍ଗ
  2. 2. ବିହଙ୍ଗ
  3. 3. ତୁରଙ୍ଗ
  4. 4. କୁରଙ୍ଗ
Answer: 2 — ପକ୍ଷୀ = ବିହଙ୍ଗ, ଖଗ, ଦ୍ୱିଜ। ଭୁଜଙ୍ଗ = ସାପ, ତୁରଙ୍ଗ = ଘୋଡ଼ା, କୁରଙ୍ଗ = ହରିଣ।
Q.23
"ସାପ" ଶବ୍ଦର ପ୍ରତିଶବ୍ଦ କେଉଁଟି?
  1. 1. ପତଙ୍ଗ
  2. 2. ପନ୍ନଗ
  3. 3. ପାବକ
  4. 4. ପବନ
Answer: 2 — ସାପ = ପନ୍ନଗ, ଉରଗ, ଭୁଜଙ୍ଗ, ସର୍ପ। ପତଙ୍ଗ = କୀଟ, ପାବକ = ଅଗ୍ନି।
Q.24
"ଜଙ୍ଗମ" ଶବ୍ଦର ବିପରୀତ ଶବ୍ଦ କେଉଁଟି?
  1. 1. ସ୍ଥାବର
  2. 2. ଚଳମାନ
  3. 3. ଗତିଶୀଳ
  4. 4. ଜୀବନ୍ତ
Answer: 1 — ଜଙ୍ଗମ (ଚଳନଶୀଳ) ର ବିପରୀତ ସ୍ଥାବର (ଅଚଳ, ଯଥା: ସ୍ଥାବର ସମ୍ପତ୍ତି)।
Q.25
"ଉତ୍କର୍ଷ" ଶବ୍ଦର ବିପରୀତ ଶବ୍ଦ କେଉଁଟି?
  1. 1. ପ୍ରକର୍ଷ
  2. 2. ଉନ୍ନତି
  3. 3. ଅପକର୍ଷ
  4. 4. ଆକର୍ଷ
Answer: 3 — ଉତ୍କର୍ଷ (ଉନ୍ନତି, ଶ୍ରେଷ୍ଠତା) ର ବିପରୀତ ଅପକର୍ଷ (ଅବନତି)।
Q.26
"ଅନୁରାଗ" ଶବ୍ଦର ବିପରୀତ ଶବ୍ଦ କେଉଁଟି?
  1. 1. ରାଗ
  2. 2. ଆସକ୍ତି
  3. 3. ପ୍ରେମ
  4. 4. ବିରାଗ
Answer: 4 — ଅନୁରାଗ (ପ୍ରୀତି) ର ବିପରୀତ ବିରାଗ। 'ରାଗ' (କ୍ରୋଧ) ଏହାର ବିପରୀତ ନୁହେଁ।
Q.27
ନିମ୍ନଲିଖିତ ମଧ୍ୟରୁ ଶୁଦ୍ଧ ବନାନଟି ବାଛନ୍ତୁ।
  1. 1. ଆବିଷ୍କାର
  2. 2. ଆବିସ୍କାର
  3. 3. ଆବିଶ୍କାର
  4. 4. ଆବୀଷ୍କାର
Answer: 1 — ଶୁଦ୍ଧ ବନାନ: ଆବିଷ୍କାର (ମୂର୍ଦ୍ଧନ୍ୟ ଷ୍କ, ହ୍ରସ୍ୱ ଇ)।
Q.28
ନିମ୍ନଲିଖିତ ମଧ୍ୟରୁ ଶୁଦ୍ଧ ବନାନଟି ବାଛନ୍ତୁ।
  1. 1. ପୁନରାବୃତ୍ତି
  2. 2. ପୁନଃରାବୃତ୍ତି
  3. 3. ପୁନରାବୃତି
  4. 4. ପୁନରାବ୍ରୁତି
Answer: 1 — ଶୁଦ୍ଧ ବନାନ: ପୁନରାବୃତ୍ତି (ପୁନଃ + ଆବୃତ୍ତି, ବିସର୍ଗ ସନ୍ଧିରେ 'ର' ହୁଏ)।
Q.29
ନିମ୍ନଲିଖିତ ମଧ୍ୟରୁ କେଉଁଟି ଅଶୁଦ୍ଧ?
  1. 1. ଲାଘବ
  2. 2. ଗୌରବ
  3. 3. ମାଧୁର୍ଯ୍ୟ
  4. 4. ସୌନ୍ଦର୍ଯ୍ୟତା
Answer: 4 — 'ସୌନ୍ଦର୍ଯ୍ୟ' ନିଜେ ଭାବବାଚକ ବିଶେଷ୍ୟ, ପୁଣି '-ତା' ଯୋଗ କରିବା ଭୁଲ। ଶୁଦ୍ଧ: ସୌନ୍ଦର୍ଯ୍ୟ ବା ସୁନ୍ଦରତା।
Q.30
"ମୃତ୍ୟୁ ପର୍ଯ୍ୟନ୍ତ" — ଏକପଦରେ ପ୍ରକାଶ କରନ୍ତୁ।
  1. 1. ଆମରଣ
  2. 2. ଅମର
  3. 3. ମରଣଶୀଳ
  4. 4. ମୃତପ୍ରାୟ
Answer: 1 — ମୃତ୍ୟୁ ପର୍ଯ୍ୟନ୍ତ = ଆମରଣ (ଯଥା: ଆମରଣ ଅନଶନ)। ଅମର = ଯାହାର ମୃତ୍ୟୁ ନାହିଁ।
Q.31
"ଯାହା ଜଳରେ ଜନ୍ମେ" — ଏକପଦରେ ପ୍ରକାଶ କରନ୍ତୁ।
  1. 1. ଜଳଜ
  2. 2. ଜଳଦ
  3. 3. ଜଳଧି
  4. 4. ଜଳଚର
Answer: 1 — ଜଳରେ ଜନ୍ମୁଥିବା = ଜଳଜ (ପଦ୍ମ)। ଜଳଦ = ମେଘ, ଜଳଧି = ସମୁଦ୍ର, ଜଳଚର = ଜଳରେ ବିଚରଣ କରୁଥିବା।
Q.32
"ଯାହାକୁ କ୍ଷମା କରିହୁଏ ନାହିଁ" — ଏକପଦରେ ପ୍ରକାଶ କରନ୍ତୁ।
  1. 1. ଅକ୍ଷମ
  2. 2. ଅକ୍ଷମଣୀୟ
  3. 3. କ୍ଷମାଶୀଳ
  4. 4. ଅକ୍ଷୟ
Answer: 2 — କ୍ଷମା କରିହେଉ ନଥିବା = ଅକ୍ଷମଣୀୟ। ଅକ୍ଷମ = ଅସମର୍ଥ, ଅକ୍ଷୟ = ଯାହାର କ୍ଷୟ ନାହିଁ।
Q.33
"ଯେଉଁ ସ୍ଥାନକୁ ଯିବା କଷ୍ଟକର" — ଏକପଦରେ ପ୍ରକାଶ କରନ୍ତୁ।
  1. 1. ଦୁର୍ଗମ
  2. 2. ସୁଗମ
  3. 3. ଦୁର୍ଲଭ
  4. 4. ଦୁର୍ଦମ
Answer: 1 — ଯିବା କଷ୍ଟକର = ଦୁର୍ଗମ। ସୁଗମ ଏହାର ବିପରୀତ, ଦୁର୍ଲଭ = ଯାହା ସହଜରେ ମିଳେ ନାହିଁ।
Q.34
"କାନରେ ତେଲ ଦେଇ ବସିବା" ରୂଢ଼ିର ଅର୍ଥ କ'ଣ?
  1. 1. ଉଦାସୀନ ବା ବେପରୁଆ ହୋଇ ରହିବା
  2. 2. ଭଲ ଭାବେ ଶୁଣିବା
  3. 3. କାନ ରୋଗର ଚିକିତ୍ସା କରିବା
  4. 4. ଗୁପ୍ତ କଥା ଶୁଣିବା
Answer: 1 — କାନରେ ତେଲ ଦେଇ ବସିବା = କୌଣସି କଥାକୁ ଧ୍ୟାନ ନ ଦେଇ ନିଶ୍ଚିନ୍ତ ବା ଉଦାସୀନ ରହିବା।
Q.35
"ଅଳ୍ପ ଜଳର ପୋଠି ମାଛ ଫର ଫର" ଢଗର ଅର୍ଥ କ'ଣ?
  1. 1. ଛୋଟ ମାଛ ଶୀଘ୍ର ମରେ
  2. 2. ଅଳ୍ପ ଗୁଣ ବା ଧନ ଥିବା ଲୋକ ବେଶି ଆଡ଼ମ୍ବର ଦେଖାଏ
  3. 3. ଅଳ୍ପ ପାଣିରେ ମାଛ ଚାଷ କରିବା ଉଚିତ
  4. 4. ଗରିବ ଲୋକ ସର୍ବଦା ଦୁଃଖୀ
Answer: 2 — ଏହି ଢଗର ଅର୍ଥ: ଯାହାର ଅଳ୍ପ ଜ୍ଞାନ ବା ସମ୍ପଦ ଅଛି, ସେ ଅଧିକ ବଡ଼ାଇ ଓ ଚଞ୍ଚଳତା ଦେଖାଏ।
Q.36
ଶୂନ୍ୟସ୍ଥାନ ପୂରଣ କରନ୍ତୁ।
ଏହି ପୁସ୍ତକଟି ଛାତ୍ରମାନଙ୍କ ପାଇଁ ଅତ୍ୟନ୍ତ ______।
  1. 1. ଉପାଦାନ
  2. 2. ଉପଦେଶ
  3. 3. ଉପାଦେୟ
  4. 4. ଉପାଦେୟତା
Answer: 3 — 'ଅତ୍ୟନ୍ତ' ପରେ ବିଶେଷଣ ଦରକାର। 'ଉପାଦେୟ' (ଉପଯୋଗୀ) ବିଶେଷଣ, ଅନ୍ୟଗୁଡ଼ିକ ବିଶେଷ୍ୟ।
Q.37
ନିମ୍ନଲିଖିତ ମଧ୍ୟରୁ ଶୁଦ୍ଧ ବାକ୍ୟଟି ବାଛନ୍ତୁ।
  1. 1. ସେ ଜଣେ ବିଦୁଷୀ ପୁରୁଷ।
  2. 2. ସେ ଜଣେ ବିଦୁଷୀ ମହିଳାମାନେ।
  3. 3. ସେ ଜଣେ ବିଦୁଷ ମହିଳା।
  4. 4. ସେ ଜଣେ ବିଦୁଷୀ ମହିଳା।
Answer: 4 — ସ୍ତ୍ରୀଲିଙ୍ଗ ବିଶେଷ୍ୟ 'ମହିଳା' ସହ ସ୍ତ୍ରୀଲିଙ୍ଗ ବିଶେଷଣ 'ବିଦୁଷୀ' ବସିବ। 'ଜଣେ' ସହ ବହୁବଚନ 'ମହିଳାମାନେ' ଭୁଲ।
Q.38
"ପିଲାଟି ହସୁଛି।" — ଏହି ବାକ୍ୟର ଭାବବାଚ୍ୟ ରୂପ କେଉଁଟି?
  1. 1. ପିଲାଟି ଦ୍ୱାରା ହସାଯାଉଛି।
  2. 2. ପିଲାଟିକୁ ହସାଉଛି।
  3. 3. ପିଲାଟି ଦ୍ୱାରା ହସାଗଲା।
  4. 4. ପିଲାଟି ହସିଲା।
Answer: 1 — ଅକର୍ମକ କ୍ରିୟାର ଭାବବାଚ୍ୟରେ କର୍ତ୍ତା ସହ 'ଦ୍ୱାରା' ଯୋଗ ହୁଏ ଏବଂ ଘଟମାନ ବର୍ତ୍ତମାନ 'ହସାଯାଉଛି' ହୁଏ। 'ହସାଗଲା' ଅତୀତ କାଳ।
Q.39
"ସେ ମୋତେ ତା' ସହିତ ଯିବାକୁ ଅନୁରୋଧ କଲା।" — ଏହାର ପ୍ରତ୍ୟକ୍ଷ ଉକ୍ତି କେଉଁଟି?
  1. 1. ସେ ମୋତେ କହିଲା, "ମୁଁ ତୁମ ସହିତ ଯିବି।"
  2. 2. ସେ ମୋତେ କହିଲା, "ତୁମେ ମୋ ସହିତ ଗଲ।"
  3. 3. ସେ ମୋତେ କହିଲା, "ମୋ ସହିତ ଯିବା ବାରଣ।"
  4. 4. ସେ ମୋତେ କହିଲା, "ଦୟାକରି ମୋ ସହିତ ଚାଲ।"
Answer: 4 — 'ଅନୁରୋଧ କଲା' ପ୍ରତ୍ୟକ୍ଷ ଉକ୍ତିରେ ଅନୁରୋଧସୂଚକ ଆଜ୍ଞା ('ଦୟାକରି … ଚାଲ') ହୁଏ, ଏବଂ 'ତା' ସହିତ' 'ମୋ ସହିତ' ହୁଏ।
Q.40
ନିମ୍ନଲିଖିତ ଅଂଶଗୁଡ଼ିକୁ ସଜାଇ ଏକ ଅର୍ଥପୂର୍ଣ୍ଣ ବାକ୍ୟ ଗଠନ କରନ୍ତୁ।
P: ୟୁନେସ୍କୋ ବିଶ୍ୱ ଐତିହ୍ୟ ସ୍ଥଳୀ
Q: କୋଣାର୍କ ସୂର୍ଯ୍ୟ ମନ୍ଦିର
R: ଭାବେ ଘୋଷିତ ହୋଇଥିଲା।
S: ୧୯୮୪ ମସିହାରେ
  1. 1. QSPR
  2. 2. SQRP
  3. 3. PQSR
  4. 4. QPSR
Answer: 1 — ଶୁଦ୍ଧ ବାକ୍ୟ: କୋଣାର୍କ ସୂର୍ଯ୍ୟ ମନ୍ଦିର (Q) ୧୯୮୪ ମସିହାରେ (S) ୟୁନେସ୍କୋ ବିଶ୍ୱ ଐତିହ୍ୟ ସ୍ଥଳୀ (P) ଭାବେ ଘୋଷିତ ହୋଇଥିଲା (R)।
